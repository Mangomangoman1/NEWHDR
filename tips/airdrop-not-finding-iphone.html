iPhone to iPhone · Check the receiving side

AirDrop can’t find
the other iPhone?

Hailey Device Repair · Reviewed October 28, 2026

Make the receiver discoverable. Send one small test.

Keep both iPhones nearby with Wi-Fi and Bluetooth on, disconnect Personal Hotspot, and check the receiving phone’s AirDrop setting. If a trusted person is missing, briefly try Everyone for 10 Minutes and resend one harmless photo. A name that appears with an approval or code prompt has reached a different stage from a missing recipient.

For nearby iPhone-to-iPhone photo or file sharing on responsive phones. Includes the iOS 16.2 receiving timer and newer AirDrop codes. Mac controls, Android/Windows transfers and cloud-library syncing need different instructions.

01 / Two roles, one test item

Keep both phones awake and close

Agree which phone is sending and which is receiving. Use one unimportant photo, not a private album or a large video. Keep both phones awake and unlocked for this comparison, close enough to read each screen. Save work before changing connections or restarting; disconnecting a hotspot interrupts devices using it.

  1. On both phones, check Settings → Wi-Fi and Settings → Bluetooth are on.
  2. If either phone is providing Personal Hotspot, disconnect that hotspot before the test. Apple lists these starting conditions.
  3. Stay nearby throughout. AirDrop’s initial local link uses direct device-to-device Wi-Fi; joining the same home router is not a prerequisite. Apple explains the local connection.

If a phone is wet, unusually hot or has a lifting screen, stop using and charging it and arrange assessment. A damaged device needs a different plan from a sharing-setting comparison.

02 / Change the receiving phone

Choose who can discover the receiver

On the receiving iPhone, open Settings → General → AirDrop. Receiving Off blocks receipt; Contacts Only limits discovery to recognized contacts. Apple’s receiving-settings guide shows this route.

For a brief test with the person beside you, select Everyone for 10 Minutes. Other nearby people may also see the device, so check the intended person before sending or accepting anything. Return to Contacts Only or Receiving Off after testing.

You can also open Control Center, hold the connectivity group, then tap AirDrop. iPhones without a Home button: swipe down from the top-right corner. Home-button models, including SE: swipe up from the bottom. See Apple’s model-specific Control Center gestures.

The receiving window expires.

On iOS 16.2 and later, Everyone for 10 Minutes returns to Contacts Only after ten minutes if signed into an Apple Account, or Receiving Off if signed out. Recheck it before a delayed retry. Older software may label the option Everyone; restore the private setting yourself. Apple describes the timer and sign-in difference.

AirDrop is missing or restricted. What should I check?

Ask the phone’s owner or family organizer to review Screen Time. Apple’s current feature-restrictions guide uses Screen Time → Content & Privacy Restrictions → Other Features; labels differ on earlier iOS.

A work or school phone can also have an AirDrop or managed-document restriction. Ask its administrator. Do not remove management profiles, turn off all parental controls or copy a protected work document into a personal app to bypass a policy.

03 / A name alone is not the match

Check the sender’s card on the receiver

For Contacts Only, the receiver’s Contacts app needs a card for the sender that includes the sender’s Apple Account email address or phone number. A nickname or an outdated number alone may not match. Confirm the right detail privately with that person; do not post account details in a troubleshooting screenshot.

If Everyone for 10 Minutes makes the person appear but Contacts Only does not, contact recognition becomes the useful lead. Correct the appropriate contact entry and retry Contacts Only. Apple’s AirDrop guide states whose contact card must contain which identity. This result does not establish an antenna fault.

You do not need to sign into someone else’s Apple Account. Automatic acceptance between your own devices signed into the same account is a separate convenience, not a requirement for sharing with another person.

04 / Visible is the next stage

Send one photo and follow the actual prompt

  1. On the sender, open Photos, select the test photo, tap Share → AirDrop, then choose the intended recipient under People.
  2. Watch the receiver’s screen. Accept the expected transfer, or follow the displayed AirDrop-code prompt. If declined, arrange another attempt with that person; repeating radio settings cannot make them accept.
  3. Open the received item before calling the copy successful. A photo sent from Photos normally appears in Photos; some other items go to Files. Keep the original until the destination copy is verified.

When both iPhones run iOS 26.2 or later, sharing with a person outside contacts can require an AirDrop code. The receiver obtains the code on their phone and gives it to the intended sender, who enters it on the sending phone. Labels may say Continue or Get AirDrop Code. Use the code displayed for this transfer, not an unlock code or Apple Account verification code. Apple’s sharing steps and the current user guide cover this version difference.

Does the code create a lasting sharing connection?

Apple says that after using an AirDrop code, you can share with that person for 30 days without another code. To end that relationship earlier, open Contacts, find the sender in Other Known, then choose Forget This Person, following the user guide. This is separate from the ten-minute discovery timer; it does not mean you should accept unexpected files.

05 / Keep the observation specific

Record what changed before changing more

The person appears after changing receiving settings
Discovery improved in this test. Finish the one-photo comparison, then restore the preferred receiving setting. Do not order hardware based on the earlier missing name.
The name appears, but approval or a code is pending
The missing-recipient stage is resolved. Check the receiving screen and software versions. Repeating discovery settings adds little information while a person still needs to approve.
Only this sender/receiver pairing fails
If another authorized Apple device is already available, compare the same small item with it. Record each phone’s receiving settings and direction. One successful pairing narrows the next check; it does not certify every radio function.

Stay close for the small test. On supported software, an initiated transfer can continue over the internet after the phones leave local range, and cellular charges may apply. Check Settings → General → AirDrop → Use Cellular Data if relevant to your plan; this is not a fix for a person missing nearby. Apple documents this in its user guide.

06 / One repeatable software check

Restart normally, then repeat the same test

Save work, know each phone’s passcode, and restart both phones normally. Models without a Home button use a volume button plus the side button for the shutdown slider; Home-button models differ, including the first-generation SE’s top button. Recheck receiving settings after startup and repeat the same photo.

If it persists on otherwise stable phones, back up important data before installing the compatible iOS update offered to each model. An older phone may not support the latest features. If a VPN is involved, ask its owner or administrator whether local networking is permitted; do not uninstall managed security software to force a test.

07 / Protect the files and connections

Stop before a reset becomes a new problem

Do not erase the originals or the phone to complete this checklist.

Erasing the phone can remove unbacked-up photos and app data. Reset Network Settings removes saved Wi-Fi networks/passwords, cellular settings and VPN/APN settings. Apple’s network-reset warning explains the lost configuration; this guide stops before that action.

If controlled checks and one restart fail, contact Apple or arrange an iPhone assessment. Involve the administrator first for restricted features or work files. Stop sooner if Wi-Fi/Bluetooth controls remain unavailable or damage changes the symptoms.

Bring both models/iOS versions, direction of sharing, receiving settings, whether Contacts Only differed from Everyone, exact prompt and comparison results. Protect important files before service. Hide account addresses and codes in public screenshots; a missing AirDrop name alone does not identify a component to replace.

Sources & scope

Official Apple instructions reviewed October 28, 2026. This is a source-based owner checklist, not a physical radio diagnosis. Menus, approval prompts and supported features vary with software and policy.
