iPad · Find the active input

iPad keyboard
won’t appear?

Hailey Device Repair · Reviewed October 27, 2026

Try an editable note. Then check the external keyboard.

Open a new note in Notes and tap its text area with a finger. If a physical keyboard is connected, use the onscreen Show Keyboard control or temporarily disconnect that keyboard and retest. A missing keyboard in one app is a different result from touch failing across the whole iPad.

For the software keyboard on iPad, mini, Air, and Pro. Includes Bluetooth keyboards and Apple keyboard cases. A physical keyboard with broken keys needs its own model’s troubleshooting.

01 / Keep the test small

Tap a place where text can actually be edited

Save or copy important work if possible before closing apps or restarting. In Notes, create a blank note and tap the normal text area with a finger, outside the drawing tools. A read-only document, drawing canvas, or toolbar is not a dependable keyboard test. Apple’s typing guide starts with tapping an editable text field.

If the iPad is wet, unusually hot, bent, or has cracked or lifting glass, stop using and charging it and arrange assessment. Apple advises stopping use when damage is suspected. Do not press a separated screen back down. If normal taps and scrolling also fail, use the frozen-device branch instead of repeating keyboard settings.

02 / An external keyboard changes the test

Ask for the onscreen keyboard explicitly

Use this branch when a physical keyboard is attached or connected. Otherwise, compare apps below.

With the text field active, look for the keyboard/shortcut control near the bottom of the screen. In Apple’s current iPad guide, tap the Keyboard Shortcut button in the Shortcuts bar, then Show Keyboard. If additional language keyboards are installed, the language button beside the suggestions is another documented route.

Controls differ by accessory and iPadOS layout. For Smart Keyboard or Smart Keyboard Folio, Apple describes tapping the lower-right keyboard button, then the show-keyboard button in its menu. The Magic Keyboard for iPad setup guide also describes touching and holding the lower-right control after tapping a text field. Follow the matching instructions if your bar looks different.

If it still does not appear, temporarily isolate only the typing keyboard and tap the same Notes text area again:

  • Bluetooth keyboard: turn that keyboard off using its normal power control. Leave other input accessories available; forgetting every Bluetooth device is unnecessary.
  • Magic Keyboard for iPad case or Smart Keyboard/Folio: support the iPad on a stable surface and detach it from the keyboard normally. These accessories do not need Bluetooth pairing, as Apple’s guides explain. Switching off Bluetooth is not the same isolation test.
  • USB keyboard: disconnect the keyboard cable. If a hub also holds storage, finish transfers and avoid unplugging the whole hub during a copy.

If the onscreen keyboard returns only when that accessory is disconnected, record the result. It points toward the external-input state or accessory interaction; it does not establish a broken screen. Reconnect afterward if needed. If you rely on an accessory for accessibility, keep a usable input method before disconnecting it.

03 / Compare the same action in two apps

Separate one app from the whole iPad

Notes shows a keyboard; the original app does not
Check that the original field is editable and that the app is in typing mode. Save work, close only that app, reopen it, and retry. This result supports an app-specific next step rather than a guessed display replacement.
Neither app shows it, but taps still work
Repeat the external-keyboard check, then try one normal restart below. Missing software input alone cannot identify a hardware part.
The keyboard appears but taps miss or stop responding
That is a touch-response problem, not simply a hidden keyboard. Record whether the same screen area fails outside the keyboard and seek assessment, especially after damage.

To quit an unresponsive app, swipe up from the bottom edge and pause, then swipe up its preview; Apple’s current guide calls the overview Exposé. Use its version selector if your iPadOS layout differs. Closing can discard unsaved work.

If only that app remains affected, check the App Store profile’s App Updates area and contact the developer. Apple’s app guidance warns that deletion can lose app-stored data. Do not delete a notes, drawing, or work app before confirming its documents are safely copied.

04 / Present, but in a different shape

Look for a small keyboard elsewhere on the screen

Restore a floating or split keyboard

Small floating keyboard: place two fingers on it and spread them apart. On layouts with a More menu, Full is another option.

Two separate halves: touch and hold the lower-right keyboard button, slide to Merge or Dock and Merge, then release. Apple lists Split Keyboard only for iPad mini and iPad (9th generation and earlier). An absent Split option on another model is not evidence of a fault.

A visible floating or split keyboard is already onscreen input. Restore the layout before following missing-keyboard recovery steps.

05 / Save work and know your passcode

Restart once, using the buttons your iPad has

When touch responds, follow Apple’s normal restart. On an iPad without a Home button, hold the top button and either volume button until the power-off slider appears. On an iPad with a Home button, hold the top button alone.

Drag the slider, wait 30 seconds, then hold the top button until the Apple logo appears. Unlock and repeat the blank-note test with the external keyboard disconnected. Know the device passcode before restarting; save work first because a restart interrupts open tasks.

Touch is frozen: which force-restart sequence applies?

On an otherwise safe, undamaged iPad, follow Apple’s frozen-iPad instructions:

  • No Home button: quickly press and release the volume button nearest the top button, then the volume button farthest from it. Hold the top button until the Apple logo appears.
  • Home button: hold Home and the top button together until the Apple logo appears.

Release at the logo. Unsaved work may be lost. If it stays frozen or stuck at startup, stop this keyboard checklist and get help for that problem. Do not continue into recovery/restore commands as a keyboard test.

06 / Keep documents in the plan

Back up before updates or a wider repair plan

If the safe checks do not resolve it, make a current backup and confirm important documents have usable copies. On a stable, undamaged iPad, check Settings → General → Software Update and follow Apple’s update instructions for the version offered to that model. Retest afterward; do not start updates while the device is damaged or overheating.

This checklist does not require an erase.

Do not use Erase All Content and Settings, a computer’s Restore command, or app deletion to make the keyboard return. These can remove data. Reset All Settings is also beyond this comparison checklist; agree on a data-preservation plan before larger changes.

For persistent failure in multiple apps, ask Apple support or arrange an iPad assessment. Send the Model Name and iPadOS Version from Settings → General → About, the Notes/original-app results, the accessory type and disconnect result, layout, restart result, and any damage history. Share symptoms without private documents or your passcode.
