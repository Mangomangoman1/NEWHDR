iPhone + Windows 11 · Find the failing link

iPhone hotspot
missing on your PC?

Hailey Device Repair · Reviewed October 22, 2026

Make it discoverable. Then test the connection.

Keep the iPhone’s Personal Hotspot screen open with Allow Others to Join enabled, then rescan Wi-Fi on Windows. If the name appears, discovery is working; a password error or “No internet” needs a different next check. Save network resets for a considered support plan.

For a responsive iPhone sharing cellular data with a Windows 11 PC over Wi-Fi. Includes the iPhone 12-and-later compatibility option. USB tethering, Android hotspots, and a home router need different setup instructions.

01 / Keep the test small

Check the phone’s internet before sharing it

Save work on both devices and finish calls or important transfers before disconnecting Wi-Fi or restarting. Test with a small webpage, not a game download. Keep the phone and PC near each other and use only your own devices or ones you are authorized to connect.

Personal Hotspot shares cellular data, not the iPhone’s current Wi-Fi connection. On the iPhone, temporarily turn Wi-Fi off in Settings and check a new webpage using cellular data; restore Wi-Fi afterward. If cellular browsing fails, address that first. With Dual SIM, the hotspot uses the line selected for cellular data. Apple explains these limits. Check the plan’s hotspot allowance before a long session; a successful connection can start background PC traffic.

02 / Keep this screen open

Let the PC find the actual hotspot

  1. On iPhone, open Settings → Personal Hotspot, or Settings → Cellular → Personal Hotspot, and turn on Allow Others to Join. Keep Wi-Fi enabled for this Wi-Fi connection.
  2. Note the network name and Wi-Fi password shown there. The hotspot name follows the iPhone’s device name. Stay on the Personal Hotspot screen until the PC connects, as Apple’s connection guide instructs.
  3. On Windows 11, make sure Wi-Fi is on and Airplane mode is off. Open the taskbar’s Network, Sound, or Battery group, then Manage Wi-Fi connections beside the Wi-Fi control. Use Refresh network list if offered. These are Microsoft’s current Windows 11 controls.

If the iPhone name is still absent, switch the PC’s Wi-Fi off and back on, then rescan while the iPhone’s hotspot screen remains open. Note whether Windows sees other nearby networks. If the PC has no Wi-Fi control at all, use its maker’s Wi-Fi-adapter guidance or Microsoft’s troubleshooting; changing the iPhone password cannot restore a missing PC adapter.

Personal Hotspot missing or unavailable on the iPhone? Check with the carrier that the line and plan support it, following Apple’s availability guidance. On a managed phone or PC, ask the administrator about restrictions. Do not remove management profiles or invent APN settings.

03 / Visible is not connected

Use the hotspot’s Wi-Fi password

Choose the iPhone’s exact name in the PC’s network list, select Connect, enter the password displayed in Personal Hotspot settings, then select Next. Use that Wi-Fi password—not the iPhone unlock code or Apple Account password. Do not publish a screenshot that exposes it.

If Windows reports a password error, recheck the current hotspot password and selected network before changing anything. A Windows PC joins through ordinary Wi-Fi; Apple’s same-account Instant Hotspot convenience for Apple devices is a different path. Signing into an Apple Account on Windows is not a prerequisite for this Wi-Fi test.

If the hotspot is visible but Windows keeps using an old saved profile, first confirm you know its current password. For your own unmanaged PC, use Settings → Network & internet → Wi-Fi → Manage known networks → the hotspot → Forget, then reconnect. This removes that network’s saved profile and requires its password again. Microsoft documents forgetting and reconnecting; it is not a fix for a name missing from the scan.

Should I turn on “Mobile hotspot” in Windows?

No. Windows Mobile hotspot makes the PC share its own connection, as Microsoft’s PC-hotspot guide explains. Here the iPhone is the provider and the PC is joining it. Leave the PC-sharing feature out of this test. Apple Devices/iTunes installation belongs to Apple’s separate USB-tethering instructions, not this Wi-Fi path.

04 / iPhone 12 models and later

Use compatibility mode as a deliberate comparison

Compatibility has a tradeoff.

Apple documents that this mode uses 2.4 GHz and WPA2 Personal for the hotspot. Apple warns that performance and Wi-Fi security may be reduced. Use a password-protected hotspot and decide whether that tradeoff fits your situation. See Apple’s technical explanation and owner warning.

If your model offers it and you choose this test, turn on Settings → Personal Hotspot → Maximize Compatibility, then rescan on Windows. Apple lists this option for iPhone 12 models and later. Older iPhones or devices without the switch should continue with the comparisons below; do not search for an unrelated reset to create the option.

If the network appears only with this setting, record that result. It points toward band/security compatibility in this pairing; it does not identify a broken phone antenna. If you later turn the setting back off, expect to reconnect and repeat the check.

05 / Compare one thing at a time

Follow the result to the next responsible device

Another device sees the hotspot; this PC does not
Focus on the PC’s Wi-Fi capability, driver, or policy. Check whether it sees a known-working Wi-Fi network. A successful second device is a clue about discovery, not proof that every phone function is healthy.
No test device sees the hotspot
Recheck Allow Others to Join, the open hotspot screen, proximity, and model compatibility. If the option itself is unavailable, involve the carrier rather than replacing Wi-Fi hardware on a guess.
The PC joins, but says “No internet”
Discovery and joining have succeeded. Repeat the iPhone’s cellular-only browsing check. If another authorized device can use the hotspot online but the PC cannot, investigate the PC’s network software or policy with support. Do not disable a work VPN or security software to force the test.

Save work, restart the iPhone normally and use Start → Power → Restart on the PC once, and repeat the same small comparison. Apple recommends restarting both. Use current iOS/Windows software when practical; protect important data before updates. Repeated restarts without recording the result add little evidence.

Once connected, consider Settings → Network & internet → Wi-Fi → the connected network → Metered connection for a limited plan. Microsoft explains metered behavior; it can reduce some background traffic but is not a hard spending or data cap. When finished, disconnect and turn off Allow Others to Join if no longer needed.

06 / Keep the working configuration

Stop before wiping network settings

If the controlled checks and one normal restart do not resolve it, contact the carrier for a missing hotspot option or cellular failure, Apple for persistent iPhone-side trouble, or computer support for a PC-specific result. Send the models, iOS/Windows versions, exact error, whether other networks appear, and the comparison results. Hide passwords, account details, and personal network names in public screenshots.

What would a network reset remove?

iPhone Reset Network Settings resets saved Wi-Fi networks/passwords, cellular settings, and previously used VPN/APN settings, according to Apple. Windows Network reset removes network adapters and their settings, then reinstalls adapters with defaults; VPN software or virtual switches may need setup again. Microsoft treats it as a last step.

These changes can remove the connection you rely on for help. Collect required credentials and configuration with the owner or administrator before any later reset. Neither a network reset nor a factory erase is needed to perform this guide’s discovery comparisons.
