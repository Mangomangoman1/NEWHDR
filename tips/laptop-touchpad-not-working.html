Windows 11 · A practical input checklist

Laptop touchpad
not working?

Hailey Device Repair · October 8, 2026

Start with safety. Restore control. Check one thing at a time.

If the pad looks normal, save your work, restart Windows, and check that Touchpad is on in Settings. A raised or distorted pad changes the plan: stop using and charging the laptop and arrange assessment.

For Windows 11 laptops. Menus and shortcuts vary by model; this is an owner checklist, not a hardware diagnosis.

First / Safety

Raised pad? Stop here.

A bulging case, separating seams, or a newly raised touchpad can indicate a swollen battery. A stiff click alone does not prove swelling, but do not press harder or push the pad flat.

If swelling or deformation is suspected, stop using and charging the laptop; disconnect external power if safe. Do not open it, pry out a battery, or keep running tests. Contact the manufacturer or a repair professional for safe handling and service. Dell identifies these warning signs; its swollen-battery guidance (PDF) explains the handling risks.

01 / Regain control

Use the keyboard or a USB mouse

For an undamaged laptop, plug in a known-working wired USB mouse if available. If it works, use it to save work and navigate; this does not establish which touchpad component is at fault.

No mouse? Use these keys.

Tab / Shift + Tab
Move to the next / previous control.
Arrow keys · Enter · Space
Move within menus, open the focused choice, or toggle a focused switch.
Windows + I
Open Settings. Look for the visible focus outline as you navigate.

Save open documents first. To restart by keyboard, press Windows + D to show the desktop, then Alt + F4. Use arrows to choose Restart and press Enter. This interrupts unsaved work; sleep or closing the lid is not a restart.

If the keyboard and an external mouse also do not respond, stop this touchpad checklist and seek help for a frozen computer. Avoid repeated forced shutdowns.

02 / Settings

Check the switch and mouse setting

  1. Press the Windows key, type touchpad settings, and open the matching Settings result with Enter. Or go to Settings → Bluetooth & devices → Touchpad.
  2. Tab to the Touchpad switch. If it is off, press Space to turn it on. Test pointer movement.
  3. Expand the Touchpad row if needed. Where offered, enable Leave touchpad on when a mouse is connected. A wireless receiver or connected mouse may affect this setting. Retest; keep the keyboard available if you disconnect the mouse or receiver.

Dell’s enabling guide includes keyboard navigation. If the page or switch is missing, continue to the driver check; missing controls do not prove a broken pad.

Check your exact model’s manual for a touchpad toggle. The key and whether it requires Fn vary. Do not try random function-key combinations or assume a corner double-tap works on every laptop.

03 / Narrow the symptom

Movement, tapping, and scrolling are different

With dry fingers and a clean, dry pad, compare these actions in a browser and another app. Follow your model’s cleaning directions; do not spray liquid into the pad.

Pointer moves, but a tap does not click
Open the Taps section in Touchpad settings and check tap-to-click options. A tap and a physical press are different actions.
Pointer moves, but two-finger scrolling fails
Check Scroll & zoom, including two-finger scrolling if offered. Test on a page long enough to scroll.
Only three- or four-finger gestures fail
Check their assigned actions. Some gestures require a precision touchpad; available controls depend on the hardware and driver.

Microsoft’s gesture guide explains supported actions. If one app alone fails, check that app’s settings or support before changing system drivers. If pressing becomes stiff or the pad changes shape, return to the safety warning.

04 / Official software

Update deliberately, then retest

A missing or outdated driver is one possible cause, according to Microsoft’s touchpad troubleshooting. Back up important files before software changes. On a work or school laptop, ask IT if installation is restricted.

  1. Open Settings → Windows Update → Check for updates. Review available updates and follow Windows prompts.
  2. Look under Advanced options → Optional updates → Driver updates. Install an applicable touchpad driver if offered; do not select unrelated optional drivers just as an experiment.
  3. Save work, restart after installation, and repeat the same pointer/tap/scroll tests. Note what changed.

If no suitable driver appears, use the laptop maker’s official support page for the exact model and Windows version. Follow its installation instructions; some precision touchpads receive their driver through Windows Update rather than a separate download. Avoid third-party driver-updater sites. See Microsoft’s driver-update instructions.

If it began immediately after a driver update

Open Start, type Device Manager, and press Enter. The touchpad may be under Human Interface Devices or Mice and other pointing devices. Expand with the Right Arrow key. Only when you can positively identify the touchpad, select it, press Alt + Enter for Properties, and inspect the Driver tab.

Record the version and date. Roll Back Driver, if available, returns to the previous driver and requires administrator permission. Follow Microsoft’s rollback directions, then restart and retest. If unavailable or the device is ambiguous, stop and ask the manufacturer or IT. Do not uninstall every HID or I2C entry: those names can cover other input hardware.

05 / A useful stopping point

Still stuck? Bring the test results.

If settings, a restart, and applicable official drivers do not help, arrange assessment. Seek help sooner after a spill, drop, repair, or physical change. An external mouse is a temporary fallback only when the laptop is otherwise safe to use.

I’d want the exact model, Windows version, when it started, whether an external mouse works, and separate results for movement, taps, physical clicks, and scrolling. Include any missing setting or Device Manager error. These observations are more useful than guessing a replacement part.

Stop before escalating the experiment.This checklist does not require a factory reset, blanket device removal, BIOS flash, or opening the case. A failed software check alone cannot confirm a hardware fault.
