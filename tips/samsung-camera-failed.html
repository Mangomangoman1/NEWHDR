Samsung Galaxy · Follow the error

Galaxy says
“Camera failed”?

Hailey Device Repair · Reviewed October 26, 2026

Restart once. Clear Camera’s cache. Check the right updates.

For a safe, responsive Galaxy phone, restart and retry Samsung’s Camera app, then clear that app’s cache if the warning remains. Check phone, Camera, and applicable Google Play system updates before assuming a camera module has failed. Preserve your photos and record each result before considering bigger resets.

For “Warning: Camera failed” or a Samsung Camera app that will not launch. A working camera that only looks blurry, a social app’s permission error, and a black phone display need different checks.

01 / Protect what already exists

Record the warning before changing settings

Note the exact message, when it began, and whether it followed an update, drop, liquid exposure, or repair. Use Settings → About phone for the model and Software information for Android/One UI details. If the phone is otherwise stable, use Samsung’s backup options and verify copies of important photos and documents before updates or app-data resets.

If the phone is wet, unusually hot, swollen, or has broken camera glass after an impact, stop repeated camera/charging tests and arrange assessment. Do not press, tap, or shake the camera bump. Save open work before restarting; have your PIN/password available for unlocking afterward.

02 / Establish one repeatable result

Restart normally, then open Samsung Camera

Open the Power menu and choose Restart, confirming if prompted. On phones with a dedicated Power button, holding it opens the menu. On Side-key models, use the Power icon in Quick settings. To open that panel, Samsung specifies a top-right swipe for One UI 7 and later; on One UI 6.1.1 and earlier, swipe down from the top with two fingers. See Samsung’s restart instructions for your model. Let the phone finish restarting before retesting.

Open Samsung Camera from the app list. If it opens, take one ordinary test photo and switch between front and rear views. Record whether one view triggers the error. If it never opens, record that instead of repeatedly relaunching it. A failure tied to one view helps an assessment, but does not prove which internal part is responsible.

03 / Target one app

Clear Camera’s cache without a phone reset

Go to Settings → Apps → Camera → Storage → Clear cache, then reopen Camera and repeat the same test. Samsung distinguishes cache from app data: this cache step removes temporary files. Confirm you selected Camera, not Gallery or another app.

Cache did not help. What would clearing Camera data change?

Samsung’s Camera-will-not-open instructions offer Settings → Apps → Camera → Storage → Clear data → Delete. This resets Camera settings to defaults. Samsung specifies that saved photos, videos, and other personal data are retained for this Camera-app procedure.

Before using it, verify your backup and note Camera preferences you want to restore. Check the app name carefully. This is not a promise about clearing data in Gallery, a messaging app, or another app: their stored data and settings can be removed. It is also not a factory reset of the phone. If the displayed action differs or you are unsure what will be deleted, stop and ask support.

If the error clears, record which step changed it and whether both views now work. Do not keep clearing app data after the same result repeats.

04 / These updates are different

Check the update offered to this device

  • Phone software: in Settings, look for Software update → Download and install. Some carrier models use System updates → Check for software updates. Follow the displayed battery/Wi-Fi requirements and offered release.
  • Camera app, if it opens: open Camera settings, then About Camera and use Update if offered. Samsung notes that Galaxy S25/One UI 7 and later place the settings gear behind the four-dot Quick settings control. Older layouts may show the gear directly. See Samsung’s update paths.
Some A/M-series and XCover models have another relevant update.

Samsung’s October 14, 2026 guidance links this error to outdated Google Play system components on listed models, including Galaxy A12, A13, A14, M13 and XCover 5. It does not establish that every Galaxy camera error has that cause.

For that branch, Samsung directs owners to Settings → Security and privacy → Updates → Google Play system update. Install an update only if offered, restart when prompted, then test Camera. If the path differs, search Settings for Google Play system update. Record an unavailable option rather than assuming the phone is up to date or forcing an unrelated update.

Retest after each update so the result remains useful. If the update itself fails or the phone starts looping, stop this camera checklist and seek help with that new problem.

05 / Temporarily exclude downloaded apps

Use Safe mode as a comparison

Safe mode disables downloaded apps temporarily. It can help separate app interference from a failure that persists with Samsung’s original software. It is not a hardware certification. Save work and know your unlock credentials before trying it.

How to enter Safe mode, test Camera, and leave

Samsung’s Safe mode instructions warn that some customizations, such as wallpaper/themes, may revert to defaults on exit. Take screenshots of a setup you want to restore.

  1. Open the Power menu. On Side-key models, hold Side + Volume down until the menu appears, then release. A Quick settings Power icon is another route.
  2. Touch and hold Power off, then tap Safe mode. After restart, confirm the Safe mode label appears at the bottom.
  3. Open Samsung Camera and repeat the same front/rear test if possible. Downloaded camera apps may be unavailable here.
  4. Use the Power menu to Restart normally to leave Safe mode. Confirm normal mode returns before testing again.

If the option is unavailable or this would interrupt an app you need, skip this comparison and record that limitation.

Camera works in Safe mode; fails again in normal mode
A downloaded-app interaction becomes a stronger lead. Review apps installed or updated around the start of the problem with support. Protect app-stored files before uninstalling anything.
Camera fails in both modes
The downloaded-app comparison did not resolve it. Software, camera hardware, or its connection can still need assessment; this result does not identify a part to buy.
06 / Save the result, not a guess

Run the Camera diagnostic if available

In Samsung Members, look under Discover → Diagnostics or Support, then Phone diagnostics → Camera. On supported devices, Settings → Device care → Diagnostics → Phone diagnostics is another route; Samsung lists Device care diagnostics for Android 12 and later. Available tests vary by model.

Follow the prompts and record the result. The first run may start a full scan; Samsung says you can stop it and select an individual test. If the Camera test is absent, skip it. A pass only describes that test, while a failure supports further assessment. Samsung documents these routes and limits.

07 / A data-preserving stopping point

Stop before erasing the whole phone

A factory data reset is not a Camera-only reset.

It erases phone data and settings. This checklist stops before that action. Agree on a verified backup and recovery plan before any later factory reset or reinstall; do not erase unbacked-up photos to see whether the warning goes away.

If the error persists, or one view consistently fails after damage, contact Samsung or arrange an Android phone assessment. Bring the model/One UI version, exact warning, update dates, front/rear behavior, cache/data-reset result, Safe mode result, diagnostic result and backup status. Mention recent damage or repair. The camera module, connector, system software and other faults need a diagnosis rather than a guessed replacement.
