Android + Windows 11 · Copy with confidence

Android charges,
but photos won’t transfer?

Hailey Device Repair · October 20, 2026

Charging proves power, not file access.

Use a cable that carries data, unlock the phone, and choose USB File Transfer before testing a small copy. If new camera files copy but older pictures are missing, check where those originals are stored before changing drivers or resetting anything.

For a responsive, unlockable Android phone and a Windows 11 PC. Pixel/Android and Samsung Galaxy labels differ; use the matching path below. This is a USB photo-copy check, not a complete phone backup or an iPhone, Mac, or locked-phone recovery procedure.

01 / Keep the only copy safe

Copy first. Leave the originals alone.

Use your own trusted PC. Save open work and create a clearly named destination folder with enough free space. Plan to Copy, not Cut or Move. Leave deletion, factory resets, storage formatting, and photo-app “Free up space” out of this connection test.

If the phone is wet, swollen, unusually hot, or has a damaged USB port, stop connecting cables and arrange assessment. Follow the wet-phone guidance for liquid exposure. If you cannot unlock it normally, USB copying may be unavailable; tell the repairer that the photos are the priority.

02 / Establish a data connection

Unlock before connecting. Then read the USB menu.

  1. Connect the unlocked phone directly to the PC using an undamaged, data-capable USB cable. For this comparison, leave the hub or dock out. A cable that charges another device has not yet passed a file-transfer test.
  2. Swipe down on the phone and tap its USB notification. Choose the matching file-transfer option below. If asked to allow access to phone data, approve only the trusted computer you intended to connect.
  3. On the PC, open File Explorer → This PC and look for the phone’s name. An automatic popup is not required.
Pixel / Google’s Android instructions
Tap Charging this device via USB, then under Use USB for choose File Transfer. Google notes that some instructions require Android 14 or later; older devices and other makers may use different labels. See Google’s USB steps.
Samsung Galaxy
Tap the Android System USB notification, then other USB options if shown. Select Transferring files / Android Auto, sometimes labeled MTP or Transferring files. “Android Auto” in this combined label does not mean a car is needed. See Samsung’s photo-copy instructions.
It started after an update, or only charges while locked?

On Galaxy devices starting with One UI 7, USB lock-screen restrictions can allow charging while blocking data, including after a restart or an extended lock. Unlock, disconnect, and reconnect as the Samsung prompt instructs. Google’s Advanced Protection USB feature also blocks new data connections while locked. Unlocking permits a new connection; turning off protection is unnecessary for this test. If a work or school policy blocks file access, ask the administrator instead of bypassing it.

03 / Prove a small copy works

Start with two photos, not the whole library

  1. If practical, take two non-sensitive test photos and note their time. On a Galaxy, open the phone in File Explorer, then Internal storage → DCIM; camera files are commonly inside Camera. If photos were saved to a supported SD card, check its DCIM folder instead. Other apps may store images elsewhere.
  2. Select just the test files. Press Ctrl+C, open the new PC destination folder, then press Ctrl+V. Wait for copying to finish; do not unplug during a transfer.
  3. Finish transfers, eject the phone from Windows if that option is offered, then disconnect. Open both copies from the PC folder. A folder thumbnail or completed progress bar alone is not the final check.

Prefer the Photos app? Use Start → Photos → Import → your connected device, choose a few items and a destination, and wait. Microsoft documents this import route. Leave any offered delete-after-import option off. If File Explorer copies successfully but Photos does not import, investigate the app/import path before blaming the cable.

If a copied video reports an unsupported format, keep both copies and record that message. Check the player’s format support before treating it as a USB failure; Google notes that playback may need a compatible codec or player.

A successful sample is not a full backup.

For the larger copy, work in manageable batches. Compare file counts and sizes, open representative photos, and play videos from the PC destination. Keep the phone originals and another independent copy before considering deletion. A USB camera-folder copy does not include every app’s data, messages, or settings.

04 / Change one variable

Use the failure to choose the next test

No phone entry and no usable USB notification
Keep the phone unlocked. Try another cable known to transfer files, then another direct PC port. Recheck the USB mode after reconnecting. Power alone does not establish a working data path.
Phone appears, but storage is empty or access is denied
Return to the phone: unlock, read the access prompt, and confirm File Transfer. If an explicit restriction remains, record it. An empty view does not prove the photos were erased.
Copy begins, then disconnects or fails repeatedly
Stop large batches. Try the same small sample with the controlled cable/port comparison. Note the exact error and whether the phone disappears. If it works only when the plug is held at an angle, stop flexing it and seek port assessment.

If available, compare the same phone and data cable on another trusted PC; compare another known-working data device on the original PC. Success elsewhere directs attention to the original computer or its setup. Failure everywhere still does not identify a specific broken part. Google recommends these cable/computer comparisons and normal restarts. Save work, restart each device once using its normal controls, and repeat the small test.

Does the PC specifically run Windows 11 N?

The N edition omits media components used for portable-device file browsing. If that is your installed edition, check Microsoft’s Media Feature Pack instructions: it is an Optional Feature for Windows N, and completing installation requires a PC restart. Save work first. This is an edition-specific check, not a driver package for every Windows PC. On a managed computer, ask its administrator to handle missing components.

05 / A missing picture may be elsewhere

A cloud gallery is not the phone’s USB folder

If the new test photos copy but older pictures do not appear, investigate their location before changing the connection. Look in the phone’s file manager for the expected filename and folder, including an SD card if used. An album name in a gallery need not be a folder with the same name.

Google Photos can still display backed-up pictures after Free up space removes their device copies. USB cannot copy an original that is no longer stored on the phone. For pictures already in Google Photos, use your trusted PC’s browser: open photos.google.com, select the item, then More → Download, following Google’s download instructions. Verify the downloaded copy too.

Do not delete a cloud item to make it “show up” over USB. Google Photos deletion can remove both cloud and device copies, including on other backed-up devices. Keep sync and account settings intact while identifying where the originals are.

06 / Stop before a reset

Bring the result, not a guessed repair

If there is still no stable copy after the controlled comparisons and one normal restart, seek the phone manufacturer’s help, Android device assessment, or computer support according to which side failed. Stop sooner for physical damage, repeated disconnects, a locked/unusable screen, or an explicit policy restriction. Do not install a random “MTP fixer,” enable USB debugging, format storage, or erase the phone to make it visible.

Share the phone model, Android/One UI version, Windows edition, exact message, USB mode, cable and PC comparisons, and whether the small files copied and opened after disconnection. Crop private files and account details from screenshots. Say clearly if the phone holds the only copy; preservation should guide the next step.
